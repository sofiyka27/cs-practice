git log — показывает список коммитов (историю): кто, когда и с каким сообщением их сделал. Можно вывести и сами изменения, но по умолчанию это просто список.

git show — показывает детали одного коммита: его метаданные (автор, дата, сообщение) и изменения (diff), которые он внёс.

git diff — показывает разницу между двумя состояниями репозитория: между рабочим каталогом и индексом, между коммитами.



git log -S"def":

Комманда показывает только коммиты, в которых изменялось количество вхождений подстроки "def"

git restore (**без флагов) отменяет изменения в рабочей директории, возвращая файл к состоянию индекса**



**git restore --source= ... позволяет взять версию файла из конкретного коммита(в данном случае HEAD-2) и поместить ее в рабочую директорию**
