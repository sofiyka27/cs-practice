рабочая папка (working directory) — где ты видишь и правишь файлы;

индекс (staging area) — промежуточная зона, куда ты добавляешь изменения перед коммитом;

коммит — сохранённая «точка» истории с изменениями и сообщением.



Git и GitHub: в чём разница

Git — это локальная система контроля версий (работает у тебя на компьютере, хранит историю, ветки, коммиты);

GitHub — это хостинг для репозиториев (место, где ты публикуешь свой Git-репозиторий, чтобы делиться им и работать в команде).
